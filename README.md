# Castle-Construction

Overview

You are the dungeon architect attempting to prevent the entrance of heroes in a retro playform style dungoen bu designing a dungeon after which a set number of heroes controlled by ai will be released with the goal of overcoming challenges. at the end, you must complete your own dungeon in less lives.

gameplay loop

dungeon creation - stage 1
playability as a standard platformer - 2
ai simulation - 3
gamification - 4
